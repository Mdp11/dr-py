- **The approved spec governs over a plan's verbatim code.** Three defects shipped in the
  Phase 5 plan's own Task 5 Step 4 block (lease leak on mid-acquire close, stuck
  `previewing`/`rebinding` flags, draft deleted on close-before-load). They were fixed
  because each violated the user-approved spec. Consequence: **the plan file's Task 5
  code no longer matches `metamodel-editor.svelte.ts`** — trust the module, not the plan.
- **`isReadOnly()` vs `isEditBlocked()` are deliberately split** in
  `metamodel-editor.svelte.ts`. `isReadOnly()` (the surface flag) folds in `_rebinding`;
  `editMetamodelBuffer` uses the narrower `isEditBlocked()`. Merging them re-introduces
  data loss: a straggler keystroke would stay in the CodeMirror doc while `_buffer`
  froze, and the sync effect would later overwrite the user's characters.
- **`MetamodelYamlEditor` tags its own transactions** with an `externalReplace` annotation
  and filters them in the `updateListener`. Without it, an external `code` replacement
  echoes back through `onChange` as a phantom edit. Do not "simplify" it away.
- **`ruff format` rewriting `except (A, B):` → `except A, B:` is CORRECT** — the repo
  targets Python 3.14, where PEP 758 makes it valid. Verified by parsing under 3.14.5.
  Do not "fix" it back.
- Inherited and still binding: honor-don't-require `mm` lease semantics (no token
  verification); the quiet predicate **excludes** `mm` (`hasModelLocks` in

## Known Issues, Not Yet Fixed
All diagnosed (not suspected), all judged non-blocking at merge. **These no longer exist
anywhere on disk — the SDD ledger was deleted — so this list is the only record.**
- **Stale-preview re-arms Rebind.** `MetamodelTab.svelte`'s Rebind button is not gated on
  `ed.previewing`, and `previewMetamodelChanges` has no `_rebinding` guard. Sequence:
  Preview → Preview again (in flight) → Rebind → rebind resolves and nulls `_preview` →
  the second preview resolves and sets `previewCurrent` back to true. The panel then shows
  a diff computed against the PRE-rebind metamodel with no staleness warning, and Rebind
  re-arms for a redundant identical-text rebind (journals a commit, bumps `model_rev`).
  One-line fix: `if (gen !== _gen || _rebinding) return;` after the diff await, or
  `|| ed.previewing` on the button.
- **Dead setters.** `setMetamodelFilename` (`frontend/src/lib/state/file.svelte.ts:27`)
  has zero callers since the drawer's deletion; its sibling `setFilename` was already dead
  the same way. TopBar renders `metamodelFilename ?? (metamodel ? 'loaded' : '—')`, so the
  UI is fine — the setters are just orphans. Delete both together.
- **`Snippet/CodeEditor.svelte` (~lines 208-221) has the identical latent echo bug** that
  was fixed in `MetamodelYamlEditor` (external `code` replacement echoes through
  `onChange`). Currently unreachable because no caller replaces `code` post-mount.
- The three `mm`-lease re-exports in `frontend/src/lib/state/index.ts` (~205-207) now have
  zero consumers (the editor module imports them by relative path).
- `discardMetamodelDraft` doesn't clear the pending lint timer (benign: the timer lints
  `_buffer` at fire time, so post-discard it lints the baseline and clears the gutter).
- `retryMetamodelLease` clears `_lockedBy` before the retry resolves — the editor is
  briefly writable mid-round-trip; typed chars are kept, nothing is lost.
- No test pins the `Workspace.svelte` close-path metamodel branch (redundant by design
  with the component's own unmount teardown).
- `commitMetamodelRebind`'s `isProjectQuiet()` guard branch is untested.
- Refresh mid-edit strands the server-side `mm` lease for the full TTL (300s). Inherent to
