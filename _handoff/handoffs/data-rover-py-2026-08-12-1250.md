## Standing Constraints
- **The diagnosis below is verified, not assumed** (2026-08-12, against current code):
  `setIssues` has exactly two callers, neither on open nor commit; `_issueCounts` updates
  from `/open`, from every commit delta and from realtime. That asymmetry IS the bug.
  Don't re-derive it — but do re-check the line numbers, they drift.
- **Do NOT wire `runValidation()` / `validateAll()` into the commit path.** It hits
  `POST /model/validate`, which re-runs the whole pipeline (`routes/validation.py:141`);
  the model can be ~80 MB, so that is the wrong cost per commit. This is the single
  constraint the brainstorm exists to design around.
- The backend already maintains a baseline issue store filled by the background
  validation sweep, with each commit splicing its conformance issues in
  (see CLAUDE.md's Phase 4 / validation-sweep sections). `state.all_issues()` is the cheap
  read and is ALREADY used inside `routes/validation.py:121` — it just isn't exposed as a
  plain GET. A new read route is a likely part of the answer, so this is probably NOT a
  frontend-only change, despite what BACKLOG.md's F-4 wording implies.
- Issue `origin` tagging matters: `validateAll` deliberately excludes `origin === 'resolved'`
  from counts (`model.svelte.ts:1002-1003`), and the working-vs-committed distinction is
  the whole subject of `routes/validation.py:39-46`. Any new read path has to be explicit
  about which of those it returns, or the panel and the count will disagree in a NEW way.
- Repo conventions that bit earlier sessions: everything runs through `pixi`; `dr-tidy`
  (ruff + mypy + pyright) is the authoritative typecheck — IDE Pyright warnings about
  unresolved `fastapi`/`redis`/`pydantic_settings` imports are environment noise.
- Fix an item and flip its BACKLOG.md status to `done` **in the same commit** (BACKLOG's
  own rule). Commit messages end with a `Co-Authored-By:` trailer.
- No push to `origin` — repo convention (BACKLOG §10); merge locally only.
- Work in-place on a branch, not a worktree: pixi envs + the `ensure_guest.sh` activation
  hook make worktrees expensive here.
