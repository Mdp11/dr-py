## Standing Constraints
- **Execution process:** subagent-driven (`superpowers:subagent-driven-development`) —
  fresh implementer per plan task, task review after each, final whole-branch review on the
  most capable model, ONE fix wave, `git merge --no-ff` into local `main`, delete branch,
  no push. This is now an 8-session precedent; the user chose it explicitly again.
- **A plan's illustrative code snippets do not outrank its behavior contract.** Ruled twice
  this session (an `$effect` reading reactive state without `untrack`; palette actions
  bypassing the file's `close()` helper). Both "plan-mandated" review findings were fixed,
  and the first was a genuine bug. Apply the same ruling next time rather than escalating.
- **Svelte 5 dialog lessons paid for this session** (they cost several fix rounds):
  - `Dialog.Root` needs a LOCAL `$state` for open, forwarded with `bind:open` **plus**
    `onOpenChange`. A plain `$derived` passed as a non-bound prop never renders content in
    tests. See `ExportArtifactsDialog.svelte`.
  - Any read of a getter backed by reactive `$state` inside a lifecycle `$effect` must go
    through `untrack()` — otherwise unrelated state changes (e.g. a peer's commit over the
    realtime feed) rerun the effect and clobber the user's in-progress edits.
    `ExportArtifactsDialog.svelte:95` is the worked example, with the comment explaining why.
  - A dialog with async work needs BOTH reset-on-open and a generation guard before every
    post-`await` state write. Reset-on-open alone does not cover close→reopen-before-settle.
    `ImportArtifactsDialog.svelte` is the worked example.
- **The Phase 1–3 backend contract is frozen.** The only backend change sanctioned this
  session was `ProjectOut.skipped_artifacts`. If a route looks wrong, raise it, don't change it.
- Viewer gating everywhere is **hide-not-disable** via `canEdit()`. Export/preview are
  viewer-allowed reads; plan/import are not.
- Frontend files are TAB-indented (prettier); Python 4 spaces (ruff). Conventional commits,
  no attribution/co-author trailers.
- The real frontend lint gate is `pixi run -e frontend bash -c 'cd frontend && npm run lint'`
  — `dr-tidy` misses things. Frontend npm scripts need `cd frontend`; pixi runs from repo root.
