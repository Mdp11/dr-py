## Standing Constraints
- **Leases are the concurrency control, not OCC** — no `view_rev`/`artifact_rev` op
  preconditions, ever (CLAUDE.md "Lease rule").
- **Staged view buffer is an ORDERED JOURNAL** — no per-entry revert; discard is
  all-or-nothing (order-dependent ops).
- **`applyViewOp` (frontend) mirrors `api/view_ops.py::apply_view_ops`** — change both or
  neither; verified branch-by-branch by reviewers.
- **Element placements never target the view root**; "move to root" is `remove_element`.
  Artifact refs DO have a real root list.
- **Never send an empty commit batch** — the backend's empty-batch early return skips lock
  release and orphans leases until TTL (the e2e loader has an explicit guard for this).
- **The real frontend lint gate is `cd frontend && pixi run -e frontend npm run lint`**
  (prettier --check + eslint). `pixi run frontend-lint` runs eslint only — a prettier
  regression shipped through that hole this session and cost a fix round. A bare
  `pixi run -e frontend npm run lint` from the repo root fails ("Missing script").

  When retiring things, sweep ALL of `src/`, `tests/`, `frontend/e2e`, and README/CLAUDE
  prose for stale present-tense references — this session needed two extra fix rounds
