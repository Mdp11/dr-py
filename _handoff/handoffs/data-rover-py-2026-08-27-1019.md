## Standing Constraints
- **K-22 (new):** `IndexSet.element_order` (element id → monotonic insertion sequence number)
  is maintained by the two element hooks ONLY (`on_element_created` assigns + increments,
  `on_element_deleted` pops) and re-derived by `rebuild()`, which REPLACES the dict object —
  never cache it across a rebuild, never assign it from anywhere else, never make a
  property/relationship hook touch it (an element never moves within `model.elements`). Only
  its ORDER is meaningful: numbers go sparse after churn, a restore re-inserts LAST, and
  `verify_consistent` checks the order invariant + distinct numbers, never the values against
  a rebuild's. The uniqueness report is byte-identical to before; five tests in
  `tests/validation/test_uniqueness.py` pin it (one wraps `model.elements` in an iteration-
  counting dict — a scoped run must never enumerate the model).
- **K-23's own hazard:** the replay tail and every commit pay `set_property` per op property;
  whatever replaces the per-write copies must be O(1) per write and must not make the
  metamodel mutable — `Metamodel` is frozen after load, `_Caches` is the only lazily-built
  state and is reset by `model_copy`. Measure which of the four per-write costs dominates
  BEFORE designing (see Plan step 1); the spec's item names three candidates and the trigram
  re-derivation may outweigh the list copies.
- **K-21:** the snapshot reader branches on the gzip magic, never on the key — no key-suffix
  branch, `encoding` column, migration or backfill. `serialize.iter_model_json` (indented) stays
  the `/model/save` + `/model/download` contract; `iter_model_json_compact` is the snapshot
  sibling. Rebind-forced, evict and baseline snapshots stay synchronous; only the periodic one
  runs on `api/snapshot_job.py`.
- **K-20:** never build a search index on a transient model; `keep_search=True` only at the
  four rebind sites (`metamodel_ops.py:187`, `commits.py:461/596/645`).
- **K-6:** `Commit.entity_states` NULL means "not captured — reconstruct"; never backfilled.
- Per-entity validator hooks stay O(entity); an O(model) cost must never move to the mutation
  boundary as a per-mutation reindex.
- `docs/` is gitignored — specs and plans never commit; everything else does.
- pixi for everything. `pixi run dr-tidy` must pass (ruff + mypy + pyright; pyright does cover
  the test files when run on them directly — no `# type: ignore` shortcuts). The tasks accept a
  check-only arg: `pixi run dr-tidy true` / `pixi run core-tidy true` modify nothing — use those
  while an implementer subagent is mid-edit. Run `pixi run frontend-install` in a fresh worktree
  before `dr-tidy`.
- **Ruff does NOT enforce import ordering here** (`ruff.toml`: `UP` on top of E4/E7/E9/F, no
  isort) — never claim otherwise in a plan or a review.
- Integration = merge commit into `main` + push (`BACKLOG.md:1225`: pushing `main` is standing
  policy). Re-check `git log origin/main` immediately before merging. The finishing skill's

## Deferred — Do Not Do
- **Folding the sequence number into `uniq_groups`** (`dict[UniqKey, dict[str, int]]`) — saves
  ~3 MiB of the 16 but changes a public structure's type for three consumers (`dirty.py`,
  `verify_consistent`, tests) and threads ordering through `_add_to_group`/`_rekey`/
  `_remove_from_group`. Declined in the spec's K-22 non-goals.
- **A sequence-number field on `Element`** — a pydantic field would leak into every save file
  and snapshot. Declined (K-22 non-goals).
- **The per-sweep hoist of the position map onto the validator** — see Done. Declined.
- **Comparing `element_order` values to a fresh rebuild's in `verify_consistent`** — a false
  mismatch by construction (sparse vs dense). The order-invariant check is the design.
- **zstd for snapshots**, **serialize-outside-the-mutex by shallow-copying properties**, **an
  `encoding` column on `Snapshot`**, **a `snapshot_gzip_level` setting**, **a skip-evict-snapshot
  shortcut** — all declined during K-21 (spec K-21 non-goals).
- Findings the K-21 final review accepted as-is — do not "fix": `decode_snapshot` returning
  `Any`; the `>= 3 chunks` assertion in `test_snapshot_codec.py`; the tautological
  `assert s.snapshot_sync is True`; the `if sync if sync is not None else …` expression; the
