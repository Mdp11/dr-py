## Standing Constraints
- **`STRINGIFY_OPTS = { lineWidth: 0, flowCollectionPadding: false }` in `yaml-edit.ts` is
  load-bearing — never change it.** Without the padding flag, an unedited parse→serialize
  round-trip of `examples/smart-city.metamodel.yaml` rewrites 126 of its 455 lines. A test in
  `yaml-edit.test.ts` round-trips that real file byte-for-byte; never weaken it.
- **Implementers must NOT run `pixi run dr-tidy`, `frontend-check`, `npm run lint`, or
  `npm run format`.** Each sweeps the whole frontend; one fix round burned ~50 minutes
  re-running them. Focused tests + reading their own diff is the implementer's gate.
  Branch-wide tidy runs once at Task 14 and is the controller's job. Backend-only tasks may
  run `pixi run backend-lint` once. This single change cut a task cycle from ~50 min to ~4 min.
- **Shared test fixture lives at `frontend/src/lib/metamodel/__tests__/fixtures.ts`.** The plan's
  test files say `import { FIXTURE } from './yaml-edit.test'` — always correct that to
  `from './fixtures'`. Cross-importing a `.test.ts` re-runs its whole suite in every importer.
- **Mutate-or-throw contract in `yaml-edit.ts`:** a command either mutates surgically or throws
  with no side effect. Use the non-creating `section()` accessor in remove/read paths; reserve
  `ensureSection` for `add*` where creating is the intent.
- **Layout is presentation, not content:** `GET/PUT /metamodel/layout` has no `mm` lease, no
  commit journal entry, last-write-wins. Owner approved this exception explicitly.
- **Layout save gate is `getRole() !== 'viewer'`** (editors+ may PUT). The plan's Task 9 note
  says "Only owner saves" and then corrects itself — the corrected form is right, per spec §5
  and Task 5's route matrix. Buffer *editing* is separately owner-only (`isEditBlocked()`).
- **Rename key-deferral:** a draft rename must NOT rewrite shared layout keys until rebind
  succeeds (peers render baseline names). Task 9 carries the mechanism.
- **`buildDiagram` (Task 7) must read endpoints from `rel.mappings`, never the `source`/`target`
  shorthand** — the shorthand is a serialization mirror and Task 7's dangling-ref test leaves a
  stale one in place.
- Strict UML notation + app-native styling (sage glass, Outfit names, gold `{id}`/`«enumeration»`,
  italic+dashed abstract). Approved mockup: `.superpowers/brainstorm/25414-1786618301/content/canvas-style-v2.html`.
- Auto-arrange is a permanent toolbar button (owner requirement), elkjs `layered`.
- Do NOT commit anything under `docs/superpowers/` or `.superpowers/`. `main` is deliberately
  ahead of origin — **never push**.
- The plan's code blocks are specifications, not transcripts. Where the `yaml` package API
  diverges, the tests are authoritative — adjust the implementation, not the tests.
