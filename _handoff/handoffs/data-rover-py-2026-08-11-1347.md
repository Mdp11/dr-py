## Standing Constraints
Phase 5 decisions (user-chosen this session, in the spec — do not relitigate):
- **Scope: raw YAML editing only.** UI-assisted form editing is a later phase.
- **Host: singleton `metamodel` workspace tab** (`mm:editor`), not a dialog/route.
- **Tiered feedback**: debounced `POST /metamodel/lint` (parse+schema only, always 200,
  NOT in the read-only-POST allowlist) while typing; full `POST /metamodel/diff` only on
  explicit Preview — per-keystroke model validation is off the table (~80MB models).
- **Lease on first divergent edit**, owner-gated; conflict → read-only keeping typed
  chars; released on close/unmount/discard/successful rebind. Editing is owner-only;
  non-owners get a read-only YAML viewer.
- **Drawer deleted this phase**; TopBar item becomes "Edit Metamodel" opening the tab.
- **localStorage draft** (`ui.metamodel.draft.<projectId>`), cleared only by rebind
  success or explicit discard; the lease does NOT survive refresh (re-acquires on edit).
- **API shape A/A**: new `GET /metamodel/raw` (stored `MetamodelRow.blob` verbatim —
  comments/order preserved; `source: "serialized"` degraded fallback) + new
  `POST /metamodel/lint`. No mode flags on existing routes; backend contract frozen, ADD only.
- **Rebind gated on preview-currency**: any edit after Preview invalidates it and
  disables Rebind — unreviewed changes can never land.
- **Initial-bind authoring out of scope**: tab entry stays disabled with no metamodel.
Inherited Phase 4 constraints (still binding): honor-don't-require `mm` semantics (no
token verification); quiet predicate excludes `mm` (`realtime.svelte.ts` — the `'mm'`→
`false` assertion in `quiet.test.ts` is correct); one generation guard per concern (the
lease module owns its own; the editor module guards only its own async).
House rules: TAB-indented frontend (prettier via `dr-tidy`); components import state
via the `$lib/state` barrel; `mount`/`flushSync` component tests (no testing-library);
conventional commits, NO trailers; beware Edit writing NULs into `.svelte` files.
