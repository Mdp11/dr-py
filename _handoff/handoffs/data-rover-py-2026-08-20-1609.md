## Standing Constraints
Architecture invariants — these are load-bearing and were each verified by review; do not
"simplify" them:
- **Hover must NEVER rebuild `flowNodes`/`flowEdges`.** The premise of the whole feature set
  (fine at 20 nodes, wrong at 300). Hover flows through `metamodel-canvas.svelte.ts` `$state`
  into per-component `$derived`s; the flow arrays' `$effect`s never read it.
- **LOD hides content with `visibility: hidden`, never `display: none` / DOM removal**, so box
  heights and therefore edge anchors are byte-identical in both modes. `nodeSize`/elk untouched.
- **`built` derives from the hoisted `parsedMm`, not `view.mm` inline** — `getMetamodelDiagramView()`
  returns a fresh object literal every recompute, so without the hoist a canvas click re-runs
  `buildDiagram` + `buildAdjacency` at O(metamodel). A call-counting test pins this; do not
  collapse the hoist back.
- **Memo caches in `.svelte.ts` state modules are plain `let`, never `$state`** — writing
  `$state` from a getter trips `state_unsafe_mutation` mid-render.
- **`revealSelection` takes the flow helpers as a PARAMETER**; the caller owns `useSvelteFlow()`
  (hooks bind context at their call site). Do not move the hook inside.
- **Each of the three node components has exactly ONE `.mm-node` CSS rule.** Do not add a second block.
- **The panel `<aside>` is a non-scrolling `flex flex-col` positioning context with an inner
  `flex-1 min-h-0 overflow-y-auto` wrapper.** The Hide button is `absolute` against the
  non-scrolling aside. An earlier version had it inside the scroll container and it scrolled
  out of reach; confirmed in a browser at 2.5x content overflow. Do not "simplify" this back.
- **All four features are read affordances available to viewers** — nothing consults `readOnly`
  or `canDragLayout`.
- Colours are CSS tokens (`var(--…)`, `color-mix`, Tailwind token classes) only, never hex literals.
- Dense docstrings explaining *why* are house style and are graded. **A docstring that overstates
  what its code does is treated as a defect** — two tasks took fix rounds for exactly that, and
  one of the final review's three Important findings was this. Check factual claims, not just presence.
- Commit trailer required: `Co-Authored-By: Claude Opus 5 (1M context) <noreply@anthropic.com>`
- Never stage anything under `docs/superpowers/` or `.superpowers/` (both gitignored).

Known IDE noise, not a defect: importing a `.svelte.ts` runes module as `'../foo.svelte'` makes
the TS server report "Module '*.svelte' has no exported member". Repo convention; `svelte-check`
passes. See `frontend/src/lib/state/__tests__/metamodel-diagram.test.ts:24`.
