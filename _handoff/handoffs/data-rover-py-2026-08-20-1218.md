## Standing Constraints
- Hover must NEVER rebuild `flowNodes`/`flowEdges` — the whole architecture (shared
  reactive store + per-component class derivation) exists for this; folding hover into
  `specToNode` was explicitly rejected (spec §3).
- LOD hides content with `visibility: hidden`, never removes it — keeps DOM heights and
  therefore edge anchors byte-identical; `nodeSize`/elk untouched (spec §4, plan Task 3).
- LOD trigger is automatic-by-zoom only (user chose this over a manual toggle); hysteresis
  `LOD_ENTER=0.4` / `LOD_EXIT=0.5`, both exported consts.
- Hover style is highlight + dim-the-rest (user chose over highlight-only); dim ~0.25
  opacity with a ~120ms transition-delay into dim so sweeping doesn't strobe; selected
  elements are never dimmed (`visualState` returns 'normal' for selected-outside-set).
- Relationship search-select fits the viewport to ALL endpoint boxes (user's explicit
  answer for multi-mapping rels); mapless-but-BOXED rels (e.g. abstract `Observes`) pan
  to their assoc box — `none` only when truly nothing is drawn.
- Search and panel TOC navigate through ONE shared `revealSelection` action so they can't
  drift; it reopens a collapsed panel (navigating by name implies wanting the form) while
  a plain canvas click deliberately does not.
- All four features are read affordances — available to viewers, no `readOnly` gates.
- API facts verified against installed `@xyflow/svelte` 1.5.2: `onnodepointerenter/leave`,
  `onedgepointerenter/leave`, `onmove(event, viewport)`, `useSvelteFlow().fitBounds(rect,
  opts)` all exist. Don't re-verify.
- Test conventions: svelte `mount`/`flushSync`/`unmount` + API spies over REAL state
  modules (mirror `metamodel-tab.test.ts`), NOT vi.mock('$lib/state') and NOT
  testing-library. xyflow node components can't mount standalone (Handle needs a flow
  store) — their logic is pure-function-tested instead; hosts wrap `SvelteFlowProvider`.
- Components take an optional `onReveal` prop as the test seam (defaults to the real
  `revealSelection` path).
- Commit messages: `feat(frontend): ...` style + the standard Claude trailer; never push
  to origin (repo convention, BACKLOG §10).
