## Standing Constraints
- **`IndexSet.rebuild()` never builds the trigram search index** (K-20). A bulk-loaded model
  starts `search_ready=False` and `search_candidates` returns `None`, which
  `routes/read.py::list_elements` answers with a byte-identical full scan. If K-6 reconstructs a
  model and search looks "broken" there, that is correct — do **not** build an index on a
  transient model, and do not add a `start_search_index_build` call to a reconstruction path.
- **`rebuild(keep_search=True)` is legal only where the entity dicts are unchanged** since the
  index was last consistent — i.e. the four live metamodel-rebind sites, and nowhere else.
  Using it where elements changed leaves a silently *wrong* index, which is worse than an absent
  one. `IndexSet._rebuild_gen` is the tripwire: it bumps on every reset so a chunked build in
  flight aborts rather than marking an incomplete index ready.
- **The `modified` half of `GET /commits/{rev}/diff` renders full `ElementOut` before/after, but
  the journal's inverse `properties_patch` carries only the touched keys.** That gap is exactly
  why the before-state has to be *persisted at commit time* rather than derived from the journal
  after the fact — it is the crux of K-6's design and the reason the obvious "just read the
  inverse ops" approach does not work.
- A new `Commit` column must be **nullable**, with `NULL` meaning "fall back to reconstruction".
  Old rows have no captured state and must keep rendering.
- Every command through pixi; `pixi run dr-tidy` must pass (pyright covers `tests/` too, so no
  `# type: ignore` shortcuts in tests).
- Integration is a **merge commit** into `main` (repo convention — see `git log`), then push.
  `BACKLOG.md:1225` records that pushing `main` is authorized standing policy.
- `pixi run dr-tidy` needs frontend deps. In a fresh worktree run `pixi run frontend-install`
  first, or `dr-tidy` dies at its `frontend-format` step on a missing `prettier-plugin-svelte`.
  Bare `npm install` picks up system Node 18 and fails the engine check — always go through pixi.
- Dead end, do not retry (K-20): dropping the element id from the indexed text buys nothing
  (30.0 s → 28.3 s measured); the cost is the property text.
