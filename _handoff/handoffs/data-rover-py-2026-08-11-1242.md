## Standing Constraints
- **Honor-don't-require `mm` semantics** (user-chosen): metamodel writers proceed when the
  lease is free or caller-held and 409 `{"detail": "metamodel locked", "holder_email": …}`
  only on a peer hold. No lock token on the request; the server never releases the caller's
  lease — the client surface releases its own. Do not "upgrade" this to token verification.
- **The quiet predicate excludes `mm`** (`hasModelLocks`, `frontend/src/lib/state/realtime.svelte.ts:98`)
  mirroring the backend's `is_model_resource`. Counting it would let a metamodel surface's
  own lease disable its own Rebind/apply button. `quiet.test.ts`'s `'mm'` case asserts
  `false` — that is the correct assertion, not a bug.
- **Diff rules** (user-chosen): typed nested tree; adds/removes carry full definitions;
  raw-document diff (no inheritance flattening); rename = remove+add, no rename detection;
  `source`/`target` are NOT diffed as attributes (they mirror `mappings[0]`; the mappings
  diff is authoritative); wire keys `from`/`to` via pydantic alias.
- **`FieldChange` must be constructed via `FieldChange.model_validate({"from": …})`** —
  mypy's PEP 681 synthesis resolves the `__init__` kwarg from the pydantic alias, so a
  `from_=` keyword call fails `core-lint` even though it works at runtime.
- **The commit-diff metamodel section is recomputed, never stored**, and is total: a
  missing id/row or unparseable blob degrades to `null` rather than 500ing the diff.
- **Lease/diff logic stays out of drawer internals** — Phase 5 deletes SwapMetamodelDrawer;
  `metamodel-lease.svelte.ts` and `MetamodelStructuralDiff.svelte` must survive it.
- **The Phase 1–3 backend contract is frozen**: ADD fields only.
- Svelte 5 dialog rules (paid for over two sessions): local `$state` + `bind:open` +
  `onOpenChange`; async flows need generation guards (the lease module has one — don't add
  a competing guard on top of it).
- Frontend files TAB-indented (run prettier before committing); Python 4-space.
  Conventional commits, NO attribution/co-author trailers. Never push to origin.
- Components import state through the `$lib/state` barrel (`frontend/src/lib/state/index.ts`),
  not submodules directly — new state exports must be re-exported there.
- `@testing-library/svelte` is NOT a dependency; component tests use `mount`/`flushSync`/
  `unmount` from `svelte` (see `MetamodelStructuralDiff.test.ts`).
- A plan's illustrative snippets do not outrank its behavior contract (ruled repeatedly).
- Beware Edit writing control bytes into `.svelte` files (git diff shows `Bin` → hunt NULs).
