## Standing Constraints
- Fix strategy chosen by user: Approach C (targeted hardening) NOW; Postgres-resident model (Approach A) is the long-term endgame when scale demands (~1M+ entities), embedded-store (B) considered but not chosen — heavy concurrent editing would hit SQLite's single-writer ceiling next.
- `/model/elements` keeps its **insertion-order contract** (docstring + tests assert it); only an `itertools.islice` micro-fix landed. The order index covers containment roots ONLY — do not "extend" it to element listing without revisiting the contract.
- `list_excluded_roots` is deliberately O(roots)-per-page (no sort, no display-name calls — those were the cost); documented limit, revisit at ~250k+ roots.
- Sweep chunk splice uses `ValidationState.replace` under `write_mutex` per chunk — the exact ops dirty-path mechanism; correctness of edit/sweep interleaving depends on it. Sweep takes ONLY write_mutex (no nested locks).
- Chunked sweep reports containment-cycle issues per-element (old full sweep: one representative) — accepted design delta 2 in the spec.
- `DATA_ROVER_VALIDATION_SWEEP_SYNC=true` is pinned in tests/api/conftest.py so the suite keeps "validation seeded after load" semantics; async behavior is unit-tested directly in tests/api/test_validation_sweep.py.
- `GET /model/status` must NEVER hydrate: it uses `SessionRegistry.peek` + `require_membership` only. Frontend Zod schema (frontend/src/lib/api/model-status.ts) depends on the exact field names.
- `markViewUnresolved()` is called ONLY in boot(); deliberately NOT in onReloadModel (comment at the site explains why — unresolving mid-session is unnecessary; refreshView is awaited before refreshSummary there).
- UUIDv7 ids sort before uppercase display names (hex-digit prefix) — don't write ordering tests with absolute positions for unnamed elements.
- Keyless element types produce n-1 uniqueness-duplicate issues for identical-props elements — pre-existing behavior, accounted for in sweep tests.
- sortedcontainers type-ignore is quarantined in src/data_rover/core/model/_sorted.py — no ignores elsewhere.
